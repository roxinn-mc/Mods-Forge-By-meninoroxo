# Mods Forge By Roxinn

This repository contains the complete set of mods I use for Minecraft Forge 1.21.11 (version 61.1.8) — all compatible and optimized for this specific setup.
Total mods in this collection: 12
Mod List & Functions
collective-1.21.11-8.32.jar - Shared core library required for many other mods to work properly
durabilitytooltip-1.1.6-forge-mc1.21.11.jar - Shows item durability information directly in tooltips
fullbrightnesstoggle-1.21.11-4.5.jar - Instantly toggle fullbright mode to see clearly in dark areas
guieffecttimer-1.21.11-1.1.jar - Displays remaining duration of active status effects on-screen
MouseTweaks-forge-mc1.21.11-2.30.jar - Adds convenient mouse controls for faster inventory management
nemos-inventory-sorting-Forge-1.21.11-1... - One-click sorting and organizing for your inventory and containers
OptiFine_1.21.11_HD_U_J9.jar - Performance boost + visual improvements: supports shaders, better FPS, and customizable graphics; works well for PVP and general gameplay
shulkerboxtooltip-forge-5.2.16+1.21.11.jar - Previews contents of shulker boxes without opening them
supermartijn642configlib-1.1.8-forge-mc... - Configuration library used by other mods to provide in-game settings
TranslationsRus.jar - Adds Russian language translations for supported mods
xaerominimap-forge-1.21.11-26.4.2.jar - Lightweight, customizable minimap showing terrain, players, and waypoints
xaeroworldmap-forge-1.21.11-1.44.2.jar - Full-screen world map that records explored areas and lets you set waypoints
Note: All mods are made specifically for Minecraft Forge 1.21.11 build 61.1.8
